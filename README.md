# contactrc-training-schoolmaaltijden
Trainingplatform for the Schoolmeals contact center team.

Interactieve training voor het contactcenter Schoolmaaltijden van het Nederlandse Rode Kruis: de overstap van Redline naar ContactRC, met nagebouwde schermen, simulaties en quizvragen.

De site staat op GitHub Pages: https://rodekruis.github.io/contactrc-training-schoolmaaltijden/

Voortgang wordt in deze versie alleen in de eigen browser bewaard. Vragen en antwoorden en het voortgangsoverzicht voor trainers werken alleen in de versie op claude.ai.
